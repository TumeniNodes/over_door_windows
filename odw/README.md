# [Mod]Over Door Windows [odw] [2026-08-24]

A small, lightweight mod for Minetest Game that adds matching over-door windows to enhance your builds.

## Features

- **Interactive Nodes**: Windows open outward with a simple right-click.
- **Full Wood Type Coverage**: Supports all default Minetest Game wood variants.
- **Door Compatibility**: Built to match and align perfectly with standard default doors:
  - Wooden Doors
  - Obsidian Glass Door
  - Steel Door (covers both solid steel and steel/glass variants)

## Installation

1. Download the mod and extract it.
2. Rename the folder to `odw`.
3. Move the folder into your Minetest `mods/` directory.
4. Enable the mod in your world configuration.
